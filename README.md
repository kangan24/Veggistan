# Veggistan
Veggistan – a vegetarian-only food delivery app designed for users who seek trust, purity, and convenience in their food choices.

For this project, I created:
•	A comprehensive PRD (Product Requirements Document) outlining the problem, solution, features, user flow and tech stack.
•	A complete Brand Guidelines Document including logo usage, color palette, typography, tone, and visual style.
•	Low-Fidelity Wireframes to understand the app structure and user journey.
•	High-Fidelity UI Designs aligned with the brand – including splash screen, login/signup, home page and user profile.

This project helped me explore the intersection of UX, UI, product thinking, and brand strategy—and I'm proud of the journey!
